## Important corrections and scope decisions

- **Part I is now a formal manuscript:** arXiv2610.23036 v1 is October 16, 2026. Its earlier blog is provenance, not a second paper; Part II (2610.06833) remains distinct.
- **Zero-Token / ZTT is one work:** arXiv2502.12214 and ACL2026 Findings711 share the authors and mechanism. One row uses the original February 17, 2025 date and links both titles.
- **Two older scope exclusions are promoted:** RecRec2607.10541 is a shared MLP TRM-family recommender and RecRec2607.12945 is a Transformer-based two-state recursive recommender. Both are Related, with their different operators made explicit. They are distinct papers with different identifiers, not duplicate acronym matches.
- **Sharing is not sufficient by itself:** SharVeT, graph-coloring/basis sharing, matrix dictionaries, CentralBank projection-table overlap, and CommonKV do not establish a repeated shared Transformer operator. These remain outside the catalog. Partial expert/FFN recurrence is labeled Related where the function itself is reused.
- **Token feedback is separated:** Trading Depth for Time is Related; R-Qwen's decoded-string feedback and Coconut-style LatentASR sequence expansion do not establish depth recurrence. Ordinary diffusion timesteps alone are likewise insufficient; Diffusion Curriculum and CoCommit have additional explicit shared Transformer execution.
- **Date precision is preserved:** arXiv v1 dates override announcement/revision dates. Some identifiers have anomalous month prefixes, including Refine Thought2511.13726 (October14,2025) and The Ignition Index2608.05160 (May26,2026); neither date is guessed from its identifier.
- **Revision warnings:** HRM Perspectives2510.00355 reports v1 errors and changed conclusions in v2. Flow Reasoning Models2606.29150 has different abstract-page and HTML titles, not two records.
- **Code availability:** TRM-QE's paper-linked repository currently returns404 and is omitted from the Code count; VLD/LARES anonymous links returning403 are also omitted. Speed is Confidence uses its current canonical repository after redirect. The recurrent VLM, ADER, and Depth as Time repositories announce future code releases and are linked as Project only. The anonymous RecRec repository contains an actual Python implementation despite an obsolete notebook path in its README. Edge-RecViT's code is explicitly linked in the primary CVPR PDF and its live README identifies the same paper and implementation.
- **MoR–Swin and MoR-ST:** these have distinct titles, DOIs, and author lists with overlapping authors. No explicit primary replacement relation was verified, so the formal records remain separate; no claim of independent experimental evidence is inferred from that bibliographic distinction.
